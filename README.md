# Baccalaureate Academy — أكاديمية البكالوريا المصرية (2026/2027)

منصة تعليمية إلكترونية متكاملة باللغة العربية (RTL) مخصصة لنظام **شهادة البكالوريا المصرية الجديد** وتشمل المراحل الدراسية الثلاث والمسارات التخصصية الأربعة.

## هيكل المشروع المنظم

```text
baccalaureate-academy/
├── index.html                      # نقطة الدخول الرئيسية للمنصة
├── README.md                       # دليل التشغيل والتوثيق الهندسي
├── supabase/
│   └── schema.sql                  # هيكل قاعدة بيانات PostgreSQL الكامل + سياسات Row-Level Security (RLS)
└── src/
    ├── config/
    │   └── supabaseClient.js       # موصل Supabase السحابي وإعدادات المزامنة الآمنة
    ├── data/
    │   └── curriculumSeed.js       # البيانات الرسمية لمقررات البكالوريا المصرية 2026/2027 (بدون أي كلمات مرور نصية)
    ├── db/
    │   └── rlsDatabaseEngine.js    # محرك قاعدة البيانات المزود بتشفير SHA-256 وحارس صلاحيات RLS
    ├── styles/
    │   └── main.css                # الهوية البصرية العربية المتجاوبة (RTL)
    └── app.js                      # منطق الواجهة التفاعلية، المشغل المرئي، الامتحانات، ولوحتي الطالب والمدير
```

## المزايا والخصائص المنفذة

1. **المراحل الدراسية الثلاث والمسارات الأربعة الرسمية**:
   - **الصف الأول الثانوي (المرحلة التمهيدية)**: العلوم المتكاملة، اللغة العربية، الرياضيات، التاريخ المصري، الفلسفة والمنطق، اللغة الأجنبية الأولى، والبرمجة والذكاء الاصطناعي.
   - **الصف الثاني الثانوي (400 درجة من الشهادة)**: المواد الأساسية المشتركة لجميع المسارات (اللغة العربية، اللغة الأجنبية الأولى، التاريخ المصري) + مادة التخصص لكل مسار.
   - **الصف الثالث الثانوي (200 درجة لتكملة الـ 600 درجة)**: مادتان تخصصيتان بمستوى متقدم لكل مسار (الطب وعلوم الحياة، الهندسة وعلوم الحاسب، الأعمال، الآداب والفنون) + التربية الدينية (نجاح من 70%).
2. **الأمان وتشفير الحسابات وسياسات RLS**:
   - لا توجد أي كلمة مرور نصية أو مفاتيح سرية داخل كود الواجهة؛ يتم التحقق من حساب المدير والطلاب عبر بصمة تشفير `SHA-256` مملحة (`Salted SHA-256`).
   - جميع عمليات الإدارة وقاعدة البيانات والنسخ الاحتياطي محمية على مستوى محرك البيانات (`assertAdminRLS`) وعلى مستوى `PostgreSQL RLS` في `supabase/schema.sql`.
3. **لوحة تحكم المدير الشاملة (`Admin Control Panel`)**:
   - إدارة الطلاب والمدرسين، المراحل والمواد، الدروس والفيديوهات والمذكرات، الامتحانات الإلكترونية، الاشتراكات والأسعار، الإحصائيات والرسوم البيانية، إعدادات Supabase، والنسخ الاحتياطي الموقّع (`Signed JSON Backup & Restore`).
